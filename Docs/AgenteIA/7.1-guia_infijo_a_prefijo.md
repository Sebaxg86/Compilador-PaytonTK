# Convertir notación de infijo a prefijo

**Fuente:** `LA2-U3-Convertir notación de infijo a prefijo.pdf`

## Propósito

Las expresiones en notación infija son comunes para las personas, pero para una computadora pueden ser más difíciles de interpretar porque debe considerar:

- Reglas de precedencia de operadores.
- Uso de paréntesis o corchetes.
- Asociatividad de operadores.

Las notaciones **prefija** y **sufija** facilitan la evaluación computacional de expresiones.

## Notaciones

Dados dos operandos `a`, `b` y un operador `O`:

| Notación | Forma | Descripción |
|---|---|---|
| Infija | `a O b` | El operador se coloca entre los operandos. |
| Sufija / Postfija | `a b O` | El operador se coloca después de los operandos. |
| Prefija / Polaca | `O a b` | El operador se coloca antes de los operandos. |

## Ejemplos

### Ejemplo 1

```txt
Entrada infija:
A * B + C / D

Salida prefija:
+ * A B / C D
```

### Ejemplo 2

```txt
Entrada infija:
(A - B/C) * (A/K-L)

Salida prefija:
* - A / B C - / A K L
```

## Procedimiento general para convertir infijo a prefijo

Dada una expresión infija, el procedimiento descrito consiste en:

1. **Invertir la expresión infija.**

   Ejemplo:

   ```txt
   A + B * C
   ```

   se convierte en:

   ```txt
   C * B + A
   ```

   Al invertir, también se deben intercambiar los paréntesis:

   ```txt
   (  ->  )
   )  ->  (
   ```

2. **Obtener la expresión sufija casi equivalente** de la expresión modificada.

   Para el ejemplo:

   ```txt
   C * B + A
   ```

   se obtiene:

   ```txt
   C B * A +
   ```

3. **Invertir la expresión sufija obtenida.**

   Resultado:

   ```txt
   + A * B C
   ```

   Por lo tanto, la expresión prefija es:

   ```txt
   + A * B C
   ```

## Diferencia importante respecto al algoritmo infijo a postfijo

Para convertir de infijo a postfijo normalmente se extraen de la pila todos los operadores que tengan precedencia **mayor o igual** que la del operador escaneado.

Para convertir de infijo a prefijo usando este método, el documento indica un ajuste:

- Se extraen de la pila los operadores que tengan precedencia **mayor** que la del operador escaneado.
- Solo para el operador `^`, se extraen operadores con precedencia **mayor o igual**.

## Precedencia de operadores

La precedencia usada en el documento es:

| Operador | Prioridad |
|---|---:|
| `+`, `-` | 1 |
| `*`, `/` | 2 |
| `^` | 3 |

## Algoritmo base

```txt
infixToPrefix(infix):

1. Invertir la cadena infix.
2. Cambiar cada '(' por ')' y cada ')' por '('.
3. Convertir la expresión modificada a postfijo con la variante indicada.
4. Invertir el resultado postfijo.
5. El resultado final es la expresión prefija.
```

## Funciones auxiliares

### Identificar operadores

```txt
isOperator(c):
    retornar verdadero si c no es letra ni dígito
```

### Obtener prioridad

```txt
getPriority(C):
    si C es '-' o '+':
        retornar 1
    si C es '*' o '/':
        retornar 2
    si C es '^':
        retornar 3
    retornar 0
```

## Conversión modificada de infijo a postfijo

El documento utiliza una pila de caracteres para operadores.

```txt
infixToPostfix(infix):

1. Agregar '(' al inicio y ')' al final de la expresión.
2. Crear una pila vacía.
3. Crear una cadena de salida vacía.
4. Recorrer cada símbolo de izquierda a derecha:

   a) Si el símbolo es operando:
      agregarlo a la salida.

   b) Si el símbolo es '(':
      meterlo a la pila.

   c) Si el símbolo es ')':
      sacar operadores de la pila y agregarlos a la salida
      hasta encontrar '('.
      Luego eliminar '(' de la pila.

   d) Si el símbolo es operador:
      si el operador es '^':
          sacar operadores mientras la prioridad del operador actual
          sea menor o igual que la prioridad del operador en la cima.
      si el operador no es '^':
          sacar operadores mientras la prioridad del operador actual
          sea menor que la prioridad del operador en la cima.
      meter el operador actual a la pila.

5. Al final, vaciar la pila hacia la salida.
6. Retornar la salida.
```

## Implementación de referencia en pseudocódigo

```txt
funcion infixToPrefix(infix):

    invertir(infix)

    para cada caracter en infix:
        si caracter == '(':
            caracter = ')'
        sino si caracter == ')':
            caracter = '('

    prefix = infixToPostfix(infix)

    invertir(prefix)

    retornar prefix
```

## Ejemplo de prueba del documento

```txt
Entrada:
x + y * z / w + u

Salida prefija:
+ + x / * y z w u
```

En el documento la producción aparece compactada como:

```txt
++x/*yzwu
```

## Complejidad

Las operaciones de pila como `push()` y `pop()` se realizan en tiempo constante. Como se escanean todos los caracteres de la expresión una vez, la complejidad temporal es lineal:

```txt
O(n)
```

## Uso como guía para un agente de IA

Para generar código intermedio desde una expresión, este documento sirve principalmente para obtener primero una representación en **notación prefija** o **notación polaca**.

Un agente debe respetar este flujo:

```txt
Expresión infija
    ↓
Invertir expresión e intercambiar paréntesis
    ↓
Convertir a postfijo usando la variante indicada
    ↓
Invertir postfijo
    ↓
Expresión prefija
```

Esta expresión prefija puede usarse después como entrada para producir Código de 3 Direcciones.
