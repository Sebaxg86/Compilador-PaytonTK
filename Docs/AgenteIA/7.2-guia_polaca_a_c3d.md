# Traducción de expresiones a Código de 3 Direcciones usando notación polaca

**Fuente:** `LA2-U3-TRADUCCION DE EXPRESIONES A C3D USANDO FORMA POLACA.pdf`

## Propósito

Este documento explica cómo traducir una expresión aritmética a **Código de 3 Direcciones** usando como punto de partida su equivalente en **notación polaca**, también llamada **notación prefija**.

## Expresión fuente

```txt
(( x / (7 - (y + 1))) * 3) - (z + (1 + x))
```

## Expresión equivalente en notación polaca

```txt
- * / x - 7 + y 1 3 + z + 1 x
```

## Procedimiento para generar Código de 3 Direcciones

El procedimiento indicado en el documento es:

1. Recorrer la expresión polaca de izquierda a derecha desde el inicio hasta encontrar la ocurrencia de un operador seguido de sus dos operandos.

2. Sustituir la subexpresión encontrada por una variable temporal.

3. Emitir la instrucción de 3 direcciones correspondiente.

   Ejemplo:

   ```txt
   t1 := y + 1
   ```

4. Repetir los pasos hasta que la expresión se reduzca únicamente al nombre de la variable temporal que contendrá el resultado total de la expresión.

## Desarrollo completo del ejemplo

| Notación polaca | Variable temporal sustituyente | Se emite |
|---|---|---|
| `- * / x - 7 + y 1 3 + z + 1 x` | `t1` | `t1 := y + 1` |
| `- * / x - 7 t1 3 + z + 1 x` | `t2` | `t2 := 7 - t1` |
| `- * / x t2 3 + z + 1 x` | `t3` | `t3 := x / t2` |
| `- * t3 3 + z + 1 x` | `t4` | `t4 := t3 * 3` |
| `- t4 + z + 1 x` | `t5` | `t5 := 1 + x` |
| `- t4 + z t5` | `t6` | `t6 := z + t5` |
| `- t4 t6` | `t7` | `t7 := t4 - t6` |
| `t7` | `-` | Resultado final |

## Código de 3 Direcciones generado

```txt
t1 := y + 1
t2 := 7 - t1
t3 := x / t2
t4 := t3 * 3
t5 := 1 + x
t6 := z + t5
t7 := t4 - t6
```

## Resultado final

```txt
t7
```

`t7` es la variable, posición o **lugar** donde queda el resultado de evaluar toda la expresión.

## Observación importante

El Código de 3 Direcciones generado respeta:

- La jerarquía de los operadores.
- El orden impuesto por los paréntesis asociativos.
- La estructura de evaluación de la expresión original.

## Regla general para un agente de IA

Un agente puede usar el siguiente criterio:

```txt
Mientras la expresión polaca no se reduzca a un solo temporal:

    1. Buscar de izquierda a derecha el primer patrón:
       operador operando1 operando2

    2. Crear una nueva variable temporal:
       t1, t2, t3, ...

    3. Emitir:
       temporal := operando1 operador operando2

    4. Sustituir en la expresión:
       operador operando1 operando2
       por:
       temporal
```

## Ejemplo de patrón

Dada la expresión parcial:

```txt
+ y 1
```

Se identifica:

```txt
operador = +
operando1 = y
operando2 = 1
```

Se genera:

```txt
t1 := y + 1
```

Y se sustituye la subexpresión:

```txt
+ y 1
```

por:

```txt
t1
```

## Relación con el atributo `.lugar`

En el estándar de generación de Código de 3 Direcciones, el último temporal producido representa el **lugar** donde queda almacenado el resultado de la expresión.

Para el ejemplo del documento:

```txt
E.lugar := t7
```

Esto significa que `t7` puede usarse después en una asignación, condición u otra expresión.

## Uso como guía para generación de código intermedio

Este documento debe usarse después de obtener la notación polaca de una expresión infija.

Flujo recomendado:

```txt
Expresión infija
    ↓
Conversión a notación polaca / prefija
    ↓
Recorrido de la notación polaca
    ↓
Sustitución por temporales
    ↓
Emisión de Código de 3 Direcciones
    ↓
Último temporal = lugar del resultado
```
